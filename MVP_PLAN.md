Already delivered: four study/post-study catalog records, partial source audits, route-scoped applicant facts, German master's EUR financing screen, four-stage descriptive journey, financial classification and conditional TK tariffs. ## Acceptance and limits

- Four separate application stages show reported evidence, unknowns, missing actions and dated sources. A planning job offer selects a possible branch; it does not grant a work title.
- Master's and graduate facts retain existing route-scoped guards. Work and graduate settlement use separate optional evidence, with manual authority review always unresolved.
- Expenses use EUR quotes with source URL, description and review date. Missing values stay unknown; explicit zero is accepted. A twelve-month projection is an applicant assumption, not a prediction of future prices.
- Financing proof and employment salaries never enter expense sums. Conditional TK references are not automatically assigned or annualized. Family costs remain incomplete.
- The quoted worksheet does not make an incomplete catalog route eligible for primary strategy placement. No dates for PR or citizenship are invented.
- The same pure composition supports normal web and static Pages; a read-only shared tool supports REST, CLI and MCP without persisting inputs.
